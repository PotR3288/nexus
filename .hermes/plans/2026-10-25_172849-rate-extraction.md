# Honest-Window Rate Math Extraction to nexus::rate

> **Status:** DRAFT — do not implement until lcooke approves.

**Goal:** Eliminate the three-way duplication of hashrate-window math (duration parsing, window labels, report-window resolution, honest-window rate computation, sample retention) by making `nexus::rate` the single implementation, consumed by both xtminer and edgecase.

**Architecture:** New `src/rate.rs` module in nexus containing the shared primitives. The free functions (`parse_window_secs`, `window_label`, `build_report_windows`, `window_rate`, `prune_samples`) are ported verbatim from xtminer's BSD-3-Clause copies; `SampleRing` (edgecase's thread-safe ring) is written fresh as a thin wrapper over those same primitives so its behavior matches by construction. Both miners delete their local copies and re-point imports. No behavior change for either miner — the shared code IS one miner's current code, and the ring wraps it.

**Tech Stack:** Rust, std only (no new nexus dependencies), existing cargo gates (fmt/clippy/test) plus per-miner Windows cross-checks.

## Decided constraints (do not relitigate)

1. **License rule is hard.** `nexus/src/lib.rs` states: "This crate must stay free of GPL-derived code … so both miners can link it." Every edgecase file is `GPL-3.0-or-later`; every xtminer file is `BSD-3-Clause`. Therefore the canonical source for everything moving into nexus is **xtminer's copies**. Edgecase's GPL versions are *deleted*, never copied in. `SampleRing` exists only in edgecase (GPL) → it is re-implemented fresh in nexus as a wrapper over the shared free functions, not ported textually.
2. **The invalid-entry warning stays local to each miner.** It looks duplicated but isn't: edgecase's message names `mining.hashrate_windows`, xtminer's inline warn names `display.hashrate_windows`. Different config keys → different messages → nothing to share. (Also avoids a logging-stack change: xtminer does not enable tracing's `log` feature, so nexus `log::warn!` records would be dropped there; edgecase enables it only transitively via tower/tonic.)
3. **Per-miner default window lists stay local.** Both are currently 30s/5m/15m/1h, but the choice is documented per-algorithm policy (edgecase's comment explains why Cuckaroo's floor is 30 s rather than xmrig's 10 s). `build_report_windows` takes the fallback as a parameter; each miner keeps its own constant.
4. **Push order:** nexus first, then xtminer and edgecase (standing convention). Nexus version bumps one minor: 0.3.0 → 0.4.0. Both miners bump their nexus rev pin to the new sha in the same commit as the re-pointing.
5. **No behavior change.** `window_rate`/`prune_samples` signatures are unchanged from xtminer's current code; edgecase's ring keeps its exact loop conditions and keep-formula (verified identical, see Current state). The only API shape change is xtminer's tuple-returning `build_report_windows` becoming the struct form.

//! Honest-window hashrate math and report-window config resolution shared by
//! xtminer and edgecase.
//!
//! Both miners display windowed rates over a cumulative work counter and both
//! accept the same duration syntax for their `hashrate_windows` config entries
//! (`90`, `"90s"`, `"5m"`, `"2h"`, `"1d"`). This module is the single
//! implementation of:
//!
//! - duration parsing ([`parse_window_secs`]) and display labels
//!   ([`window_label`]),
//! - report-window resolution with invalid-entry reporting
//!   ([`build_report_windows`], [`ReportWindows`]),
//! - honest-window rate math over (time, cumulative-total) samples
//!   ([`window_rate`], [`prune_samples`]) — a window that has not fully
//!   elapsed returns None, never a short-slice estimate,
//! - the thread-safe sample ring edgecase's sampler/monitor share
//!   ([`SampleRing`]).
//!
//! Provenance: `parse_window_secs`, `window_label`, and the rate math are
//! ported verbatim from xtminer (BSD-3-Clause) — `config.rs`, `mining.rs`,
//! and `rate.rs`. [`SampleRing`] is new code written as a thin wrapper over
//! those same primitives so its behavior matches by construction. No
//! GPL-derived source was copied into this crate (see the license note in
//! `lib.rs`).

use std::sync::Mutex;
use std::time::{Duration, Instant};

const SECS_PER_MINUTE: u64 = 60;
const SECS_PER_HOUR: u64 = 3_600;
const SECS_PER_DAY: u64 = 86_400;

/// Parse a `hashrate_windows` config entry into seconds. Accepts a bare
/// integer (seconds) or digits with an s/m/h/d suffix. Trims surrounding
/// whitespace. Overflow returns None rather than wrapping.
pub fn parse_window_secs(entry: &str) -> Option<u64> {
    let entry = entry.trim();
    if entry.is_empty() {
        return None;
    }
    // Pure integer first (seconds).
    if let Ok(n) = entry.parse::<u64>() {
        return Some(n);
    }
    // Then digits + unit suffix.
    let split = entry.find(|c: char| !c.is_ascii_digit()).unwrap_or(entry.len());
    let (num, suffix) = entry.split_at(split);
    if num.is_empty() {
        return None;
    }
    let n: u64 = num.parse().ok()?;
    let mult = match suffix.to_ascii_lowercase().as_str() {
        "s" => 1,
        "m" => SECS_PER_MINUTE,
        "h" => SECS_PER_HOUR,
        "d" => SECS_PER_DAY,
        _ => return None,
    };
    n.checked_mul(mult)
}

/// Display label for a window length: `45s`, `5m`, `2h`, `1d`.
pub fn window_label(secs: u64) -> String {
    if secs >= SECS_PER_DAY && secs.is_multiple_of(SECS_PER_DAY) {
        format!("{}d", secs / SECS_PER_DAY)
    } else if secs >= SECS_PER_HOUR && secs.is_multiple_of(SECS_PER_HOUR) {
        format!("{}h", secs / SECS_PER_HOUR)
    } else if secs >= SECS_PER_MINUTE && secs.is_multiple_of(SECS_PER_MINUTE) {
        format!("{}m", secs / SECS_PER_MINUTE)
    } else {
        format!("{}s", secs)
    }
}

#[cfg(test)]
mod tests {

    #[test]

        assert_eq!(parse_window_secs("90"), Some(90));

        assert_eq!(parse_window_secs("5m"), Some(300));
        assert_eq!(parse_window_secs("2h"), Some(7200));
        assert_eq!(parse_window_secs("1d"), Some(86_400));
        assert_eq!(parse_window_secs(" 5m "), Some(300));
        // Overflow must not wrap into a silently huge window.
        assert_eq!(parse_window_secs("99999999999999999999d"), None);
        assert_eq!(parse_window_secs("m"), None);
        assert_eq!(parse_window_secs(""), None);
        assert_eq!(parse_window_secs("5x"), None);
    }

        assert_eq!(window_label(45), "45s");
        assert_eq!(window_label(300), "5m");
        assert_eq!(window_label(7200), "2h");

```rust
/// Resolved report-window set: the live (or default) windows plus the
/// configured entries that failed to parse. `windows` is sorted
/// narrowest-first and deduped by length, and is never empty — an all-invalid
/// config falls back to the caller-supplied default.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ReportWindows {
    /// (window seconds, display label), sorted narrowest-first, deduped.
    pub windows: Vec<(u64, String)>,
    /// Configured entries that failed to parse — the caller warns about these
    /// (each miner names its own config key in the warning text).
    pub invalid: Vec<String>,
}

impl ReportWindows {
    /// Widest configured window in seconds. [`build_report_windows`] never
    /// returns an empty `windows` list, so this cannot miss.
    pub fn widest_secs(&self) -> u64 {
        self.windows
            .iter()
            .map(|&(secs, _)| secs)
            .max()
            .expect("build_report_windows never returns an empty window list")
    }
}

/// Build the report windows from configured `hashrate_windows` entries
/// (durations — `90`, `"90s"`, `"5m"`, `"2h"`, `"1d"`). Unparseable or zero
/// entries come back in `invalid` for the caller to warn about; if nothing
/// valid remains, `default` is used. The result is sorted narrowest-first
/// (display order depends on it) and deduped by length.
pub fn build_report_windows(entries: &[String], default: &[(u64, &str)]) -> ReportWindows {
    let mut invalid = Vec::new();
    let mut windows: Vec<(u64, String)> = Vec::new();
    for entry in entries {
        match parse_window_secs(entry) {
            Some(0) => invalid.push(format!("{entry} (zero — must be > 0)")),
            Some(secs) => windows.push((secs, window_label(secs))),
            None => invalid.push(entry.clone()),
        }
    }
    if windows.is_empty() {
        return ReportWindows {
            windows: default.iter().map(|&(s, l)| (s, l.to_string())).collect(),
            invalid,
        };
    }
    windows.sort_by_key(|&(secs, _)| secs);
    windows.dedup_by_key(|w| w.0);
    ReportWindows { windows, invalid }
}
```

**Step 1: Append this code** — `window_rate` and `prune_samples` are byte-for-byte xtminer's current implementations; `prune_to` is a private extraction of the shared retention loop so Task 4's ring reuses it instead of hand-syncing:

```rust
/// Hashes per second over the last `window_secs`, or `None` while that window
/// has not yet fully elapsed since the miner started (`Soon`).
///
/// Measured between `(timestamp, cumulative total)` samples recorded once per
/// report tick. The newest sample at or before the window boundary anchors
/// the rate, so the span is always `window_secs .. window_secs + interval` —
/// never a shorter ramp-up slice pretending to be the window.
pub fn window_rate(
    samples: &[(Instant, u64)],
    started: Instant,
    now: Instant,
    current_total: u64,
    window_secs: u64,
) -> Option<f64> {
    // Until the window has elapsed once there is no honest rate for it.
    if now.duration_since(started).as_secs_f64() < window_secs as f64 {
        return None;
    }
    // The first sample qualifies by construction, so this cannot fail after
    // the readiness check above — treat any miss as Soon regardless.
    let &(anchor_time, anchor_total) = samples
        .iter()
        .rev()
        .find(|&&(st, _)| now.duration_since(st).as_secs_f64() >= window_secs as f64)?;
    let elapsed = now.duration_since(anchor_time).as_secs_f64();
    Some((current_total - anchor_total) as f64 / elapsed)
}

/// Drop samples older than the retention bound — they can no longer anchor
/// any window. The margin matters: [`window_rate`] anchors on a sample AT or
/// BEFORE the window boundary, so without it the pruned frontier (age <=
/// window) could never satisfy that anchor and the widest window would
/// flicker to Soon forever. One sample is always kept regardless of age.
pub fn prune_samples(
    samples: &mut Vec<(Instant, u64)>,
    now: Instant,
    interval_secs: u64,
    widest_window_secs: u64,
) {
    let keep_secs = widest_window_secs as f64 + interval_secs as f64;
    prune_to(samples, now, keep_secs);
}

/// Retention rule shared by [`prune_samples`] and [`SampleRing::push_sample`]:
/// drop samples older than `keep_secs`, always keeping at least one.
fn prune_to(samples: &mut Vec<(Instant, u64)>, now: Instant, keep_secs: f64) {
    while samples.len() > 1 && now.duration_since(samples[0].0).as_secs_f64() > keep_secs {
        samples.remove(0);
    }
}
```

```rust
/// Thread-safe ring of (sample_time, cumulative_total) samples with
/// honest-window rate lookup. Written by one sampler thread; readers clone
/// under a short lock that is never held across a sleep. The window math is
/// [`window_rate`] itself — this type only owns the shared state.
pub struct SampleRing {
    /// Process/task start: the anchor for "window fully elapsed" checks.
    start: Mutex<Instant>,
    /// (sample instant, cumulative total) — appended by the writer, cloned
    /// by readers under a short lock.
    samples: Mutex<Vec<(Instant, u64)>>,
}

impl SampleRing {
    pub fn new(start: Instant) -> Self {
        Self {
            start: Mutex::new(start),
            samples: Mutex::new(Vec::new()),
        }
    }

    /// The start instant (for the API's window-elapsed checks).
    pub fn start_instant(&self) -> Instant {
        *self.start.lock().unwrap()
    }

    /// Append a sample and prune everything older than `keep_secs` — the
    /// caller derives that from the widest LIVE window so a hot-reload that
    /// widens or narrows the windows takes effect on the next sample. The
    /// lock is held only for the push/prune, never across a sleep.
    pub fn push_sample(&self, at: Instant, total: u64, keep_secs: f64) {
        let mut samples = self.samples.lock().unwrap_or_else(|e| e.into_inner());
        samples.push((at, total));
        prune_to(&mut samples, at, keep_secs);
    }

    /// Rate over the last `window_secs` — see [`window_rate`]. A window that
    /// has not yet elapsed returns None rather than a short-slice rate.
    pub fn window_rate(&self, window_secs: u64, current_total: u64) -> Option<f64> {
        let now = Instant::now();
        let start = self.start_instant();
        let samples = self.samples.lock().unwrap_or_else(|e| e.into_inner());
        window_rate(&samples, start, now, current_total, window_secs)
    }

    /// Backdate the start — test-only, so windowed-rate logic can be
    /// exercised without sleeping.
    #[cfg(test)]
    pub fn backdate_start(&self, secs: u64) {
        *self.start.lock().unwrap() = Instant::now() - Duration::from_secs(secs);
    }

    /// Seed the ring directly — test-only.
    #[cfg(test)]
    pub fn seed_sample(&self, at: Instant, total: u64) {
        self.samples
            .lock()
            .unwrap_or_else(|e| e.into_inner())
            .push((at, total));
    }
}
```

## Risks & tradeoffs

- **Behavior drift:** mitigated by construction — free functions are xtminer's verbatim code; `SampleRing` delegates to them and carries an equivalence test (Task 4). Edgecase's ring loop condition and keep-formula were verified identical before writing this plan.
- **xtminer logging asymmetry** (tracing `log` feature off there, on in edgecase via tower): avoided by keeping the invalid-entry warning local per miner (Decided constraint 2). Do not "fix" this as part of this work — it would change which nexus log lines appear in xtminer's console.
- **API shape change** (tuple → struct) touches 2 production call sites + ~3 test fns in xtminer; mechanical, compile-checked.
- **`widest_secs` invariant:** the builder guarantees non-empty `windows`; both current fallbacks were 3600 anyway, so no numeric behavior change. The `expect` documents the invariant instead of hiding a magic number.
- **Pin coupling:** miners must not build against nexus < new sha; push order (nexus → miners) prevents a broken intermediate state on GitHub.
